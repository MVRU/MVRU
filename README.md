# Hi, I'm Marina Milo

I'm a software engineer and Information Systems Engineering student at UTN FRRo, based in Argentina. I build end-to-end software for domains where reliability, traceability, and clear decisions matter.

Right now, I work on private systems for labor and social-security LegalTech and union management. I can't share their code or clients, but they shape how I approach data models, access control, testing, and long-term maintenance.

🧉 Currently working on my Final Degree Project and testing ideas where they matter: in real systems.

## Current focus

I'm exploring how to evaluate LLM behavior in structured-output workflows: where a response can be valid in form and still be wrong in substance. My public work on that question is [`llm-abstention-evals`](https://github.com/MVRU/llm-abstention-evals), a small reproducible benchmark for abstention in structured-output LLM classifiers.
